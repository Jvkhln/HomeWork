# Google Sheets + Apps Script backend — тохируулах заавар

Өгөгдлийн сан = таны Google Sheet (`1Q6zw3ylYDCeKoEUuXey3Pu7lQT8LMc_r8e2jyHa8cTM`).

## Sheet-ийн бүтэц

| Tab | Үүрэг | Бичих эсэх |
|---|---|---|
| **1-р tab** | Багшийн нэвтрэх нэр, нууц үг, нэр | Зөвхөн уншина |
| **2-р tab** | Сурагчийн нэвтрэх нэр, нууц үг, овог нэр, анги, код | Зөвхөн уншина |
| Schedule | Хичээлийн хуваарь | Систем |
| Homework | Гэрийн даалгавар | Систем |
| Submissions | Даалгаврын явц / үнэлгээ | Систем |
| Groups | Ангийн хэсгүүд (бүлгүүд) | Систем |
| Leaders | Хэсгийн ахлагчид | Систем |
| StudentData | Сурагчийн хэсэг / ахлагчийн тэмдэглэгээ | Систем |
| Subjects | Хичээлийн төрлүүд | Систем |
| AuditLog | Үйлдлийн түүх | Систем |

Эхний 2 tab-д систем **хэзээ ч бичихгүй**. Тэдгээртэй ижил нэртэй tab байвал (жишээ нь 2-р tab-ыг "Schedule" гэж нэрлэсэн) өгөгдлийг `db_Schedule` гэх мэт угтвартай tab-д хадгална.

### Эхний 2 tab-ын баганууд
Толгойн нэрээр таньна (монгол/англи):
- Багш: `Нэвтрэх нэр` (`username`), `Нууц үг` (`password`), `Нэр`
- Сурагч: `Нэвтрэх нэр`, `Нууц үг`, `Овог нэр`, `Анги`, `Код`

Толгой танигдахгүй бол байрлалаар: 1=нэвтрэх нэр, 2=нууц үг, 3=нэр, (сурагч) 4=анги, 5=код.
Сурагч нэвтрэх нэрээр **эсвэл кодоор** нэвтэрч болно. Нууц үг нь энгийн текст эсвэл SHA-256 hex хэш байж болно.
Нууц үгийн баганыг `Format → Number → Plain text` болговол "0123" шиг тэгээр эхэлсэн нууц үг алдагдахгүй.
Сурагчийн **код давхардахгүй, өөрчлөгдөхгүй** байх ёстой — хэсэг/ахлагчийн мэдээлэл кодоор холбогддог.

## Суулгах

1. Sheet → **Extensions → Apps Script**. `Code.gs`-ийн агуулгыг `apps-script/Code.gs`-ээр бүрэн солино. (Хүсвэл Project Settings → "Show appsscript.json" асаагаад `appsscript.json`-ийг мөн хуулна.)
2. Функц сонгогчоос **`initAllSheets`** → Run → зөвшөөрөл өгнө (8 өгөгдлийн tab үүснэ).
3. **`diagnose`** → Run → Execution log-д хэдэн багш/сурагч уншигдсаныг шалгана.
4. **Deploy → New deployment → Web app**: Execute as = **Me**, Who has access = **Anyone**. `/exec` URL-ийг хуулна.
5. Веб апп → багшаар нэвтэрсний дараа доод талын **Системийн тохиргоо** → URL оруулж холбоно.
   (Эсвэл build-ийн үед `VITE_GAS_URL=<url>` гэж өгч болно — `.env.example`-ийг үз.)

> Код өөрчилсөн бол **Deploy → Manage deployments → Edit → Version: New version** хийхгүй бол хуучин код ажилсаар байна. Тохиргооны цонхны "Холболт шалгах" хуучин хувилбарыг мэдэгдэнэ.

## Найдвартай байдлын зарчим

- Апп хурдан ажиллахын тулд локал төлөвөөр ажиллаж, өөрчлөлт бүрийг **дараалалд** оруулан Sheet рүү илгээнэ. Сүлжээ тасарвал алдагдахгүй, автоматаар дахин оролдоно (backoff), хуудас дахин ачаалсан ч хадгалагдаагүй өөрчлөлт үлдэнэ. Толгойд хадгалалтын төлөв (✓ / хадгалж байна / N хадгалагдаагүй) харагдана.
- Sheet-ээс татахдаа хадгалагдаагүй өөрчлөлт байвал **эхлээд илгээнэ** (дарж бичихгүй). Апп 45 секунд тутам болон таб руу буцахад автоматаар шинэчилнэ.
- Бичилт бүр `LockService`-ээр түгжигдэнэ; upsert түлхүүрээр хийгдэнэ (давхардахгүй, дахин илгээхэд аюулгүй); хуучин `updatedAt`-тай бичилт шинэ өгөгдлийг дарахгүй.
- Бүх нүд текст форматтай (огноо/тоо/томьёо автоматаар хувирахгүй, `=...` томьёо болж ажиллахгүй). Уншихдаа баганын төрлөөр буцаана.
- Эрх сервер дээр шалгагдана: багш — бүгд; ахлагч — өөрийн ангийн үнэлгээ/даалгавар; сурагч — зөвхөн өөрийн "шалгуулахаар илгээх". Багш баталгаажуулсныг ахлагч дарахгүй. AuditLog-ийн хэрэглэгчийг сервер өөрөө тавина.
- Токен HMAC-ээр гарын үсэгтэй (24 цаг); эрх/идэвхтэй эсэхийг хүсэлт бүрд Sheet-ээс шинээр тодорхойлно. 5 буруу оролдлогын дараа 10 минут түгжинэ.
- Нийтийн самбар (нэвтрээгүй) зөвхөн нууц үг, овог нэр, кодгүй өгөгдөл авна.

## Хэсэг, ахлагч
- Ахлагч = `StudentData` дахь `isLeader=TRUE` (багш апп-аас хэсэг хуваах/ахлагч томилох үед автоматаар бичигдэнэ). Багш Sheet дээр гараар `isLeader`-г засаж болно — дараагийн нэвтрэлтээс хүчинтэй.
- Сурагчийн нэр/анги/код 2-р tab-аас ирнэ. Апп дээр тэдгээрийг засвал Sheet-ийн утга сэргээгдэнэ — өөрчлөхдөө 2-р tab-ыг засна. 2-р tab-д байхгүй (апп-аас нэмсэн) сурагч жагсаалтад орох боловч нэвтэрч чадахгүй.
